# MiniStats 0.3.1

- 正式安装包改用 Xcode 26.6 和 macOS 26.5 SDK 构建，与本地开发版统一，修复新版 macOS 上两版原生控件外观不同的问题。
- 构建流程校验 Xcode 版本和应用实际链接的 SDK，避免意外使用旧工具链。
- 修复自动发布流程查询 Release 草稿失败的问题。

原生界面仍遵循当前 macOS 的系统外观，开发版保留 DEV 标记。开机自启及资源监控功能保持不变。

本次安装包适用于 Apple Silicon（arm64），要求 macOS 13 或更新版本；不包含 Intel 版本。安装包及更新清单使用 EdDSA 签名校验，应用仍使用本地临时签名，未进行 Apple Developer ID 签名或公证。更新安装会重启应用，内存中的历史曲线重新积累。
