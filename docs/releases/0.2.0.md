# MiniStats 0.2.0

- 正式版新增“检查更新”入口，可选择每 24 小时自动检查。
- 通过 GitHub Releases 分发更新，安装包和更新清单使用 EdDSA 签名校验。
- 开发版禁用更新，与正式版保持独立。

此版本是更新能力的首次安装版本，旧版需手动安装一次。更新安装会重启应用，内存中的历史曲线重新积累。当前使用本地临时签名，未进行 Apple Developer ID 签名或公证。

本次安装包适用于 Apple Silicon（arm64），要求 macOS 13 或更新版本；不包含 Intel 版本。发布前仍需手动验收“检查更新”入口、自动检查开关及更新对话框。
