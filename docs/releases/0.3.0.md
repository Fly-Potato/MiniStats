# MiniStats 0.3.0

- 正式版详情弹窗新增“开机自启”开关，开启后登录 macOS 时自动启动。
- 自启状态与系统登录项同步；需要系统批准时提供设置入口，注册失败时显示原因。
- 开发版和未打包程序禁用开机自启，避免同时自动启动多个版本。

开机自启默认关闭。建议将 MiniStats.app 放到 `~/Applications` 或 `/Applications` 后开启；关闭开关不会退出当前应用。

本次安装包适用于 Apple Silicon（arm64），要求 macOS 13 或更新版本；不包含 Intel 版本。安装包及更新清单使用 EdDSA 签名校验，应用仍使用本地临时签名，未进行 Apple Developer ID 签名或公证。更新安装会重启应用，内存中的历史曲线重新积累。
